# Lignin Conformer Generation (L0 Example)

[< Back: Inference](inference.md)

This guide demonstrates how to train and generate conformers for structurally flexible molecules like **Lignin (L0)**.

The "L0" molecule is one of the 100 molecules generated by the miscanthus example in the [LigninBuilder](https://github.com/jvermaas/LigninBuilder) tool. It features flexible glycosidic linkages and ring systems that require special handling in generative models.

## Key Features Used

*   **Robust Reconstruction**: Prevents atomic collapse during Backbone -> All-Atom reconstruction by using stable local coordinate frames.
*   **Geometric Refinement**: A physics-free refinement mode that resolves steric clashes using topology constraints.
*   **Topology Constraints**: Automatically inferred from the molecule's bond graph (PSF/GRO) to enforce ring planarity and protect geminal hydrogens.

---

## Step 0: Data Preparation

The example data is included in this repository at `data/miscanthus/`:
*   `L0.pdb`: Reference structure (coordinates).
*   `L0.psf`: Topology (bonds/connectivity).
*   `L0.npz`: Training data (extracted backbone trajectories).

> **Note**: These files are typically generated by molecular dynamics simulations or tools like LigninBuilder. For this example, the provided small dataset is used, augmented with `scale_factor: 7.0` in the config.

---

## Step 1: Training the Diffusion Model

To generate new conformers, a diffusion model is first trained on the backbone structure.

```bash
# Train for ~10 epochs (fast convergence for single molecule)
msgen train_diffusion \
  --config configs/verify_l0_local.yaml \
  --out-dir runs/lignin_training
```

This will produce checkpoints in `runs/lignin_training/checkpoints/`. The final checkpoint (`final.pt` or best validation checkpoint) will be used for generation.

> **Pretrained Model**: If you want to skip training, you can use the provided checkpoint at `runs/verify_l0_geo/checkpoints/final.pt`.

---

## Step 2: Generation (Sampling & Refinement)

Run the `msgen sample` command using the trained checkpoint. The critical flags for valid lignin generation are `--refinement-mode geometric` and `--connectivity`.

```bash
# Generate 100 conformers
msgen sample \
  --diff-ckpt runs/lignin_training/checkpoints/final.pt \
  --diff-config configs/verify_l0_local.yaml \
  --topology data/miscanthus/L0.pdb \
  --connectivity data/miscanthus/L0.psf \
  --refinement-mode geometric \
  --n-samples 100 \
  --batch-size 10 \
  --out-dir runs/lignin_generation_example \
  --output-formats pdb
```

### Breakdown of Arguments

*   `--refinement-mode geometric`: Enables the clash-removal refinement loop. Essential for preventing "ghost" atoms.
*   `--connectivity data/miscanthus/L0.psf`: Provides the bond graph. The pipeline uses this to:
    *   Enforce ring rigidity for 3-8 membered rings.
    *   Protect geminal Hydrogens from collapsing.
*   `--topology data/miscanthus/L0.pdb`: Provides the reference template for reconstruction.

---

## Step 3: Analysis

The generated structures are saved in `runs/lignin_generation_example/refined.pdb`.

**Visualization**: Open the PDB in VMD. You should see:
*   Physically plausible structures with no overlapping atoms.
*   Correct ring puckering and planarity.
*   Valid tetrahedral geometry at CH2/CH3 centers.

The pipeline ensures `CONECT` records are written to the PDB, so bonds are visualized correctly.
